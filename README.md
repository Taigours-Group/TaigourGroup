## 🏛️ About Us

**Taigour Group** is a dynamic multi-industry organization headquartered in **Janakpurdham, Dhanusa, Nepal**. We transform industries by delivering breakthrough solutions in technology, business, culture, and lifestyle — empowering individuals, supporting creativity, and driving sustainable growth in every venture we create.

**Highlights:**
- ✨ Premium warm-gold design system with glassmorphism UI
- 🌐 Interactive Three.js particle network in the hero section
- 📱 Fully responsive — optimized layouts from small phones to ultra-wide screens
- ⚡ Scroll-triggered animations via IntersectionObserver
- 🔍 Rich SEO — Open Graph, Twitter Cards & Schema.org structured data
- 💬 WhatsApp-integrated contact form with client-side validation
